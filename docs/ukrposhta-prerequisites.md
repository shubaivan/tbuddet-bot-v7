# Інтеграція Укрпошти — що потрібно отримати від Укрпошти

Чек-лист підготовки до інтеграції Укрпошти як другого способу доставки (поруч із Новою Поштою). Усі сервіси Укрпошти безкоштовні для базового обсягу, але потребують реєстрації як бізнес-користувача.

---

## 1. Бізнес-кабінет Укрпошти

Зареєструватися на одному з порталів:
- https://cabinet.ukrposhta.ua (основний)
- https://ok.ukrposhta.ua (Укрпошта Онлайн — для відправлень)

Що знадобиться:
- ЄДРПОУ / ІПН
- Юридична назва (ФОП / ТОВ)
- Контактна особа + телефон + email
- Юридична адреса

Підтвердження зазвичай протягом **1–2 робочих днів**.

---

## 2. API-токени

Після верифікації кабінету в розділі **"Інтеграція"** / **"API"** треба згенерувати **bearer-токени**:

| Токен | Призначення | Без чого не обійтись |
|---|---|---|
| **Address Classifier API** | Довідник міст і відділень для вибору в чекауті | Так — фронтенд показу адрес |
| **Shipments API (Production)** | Створення ТТН, друк етикеток, відстеження | Так — для роботи замовлень |
| **Sandbox tokens** | Тестове середовище | Бажано — для розробки без впливу на real-замовлення |

Деякі функції (наприклад, дрібнопакетна доставка з пільговим тарифом) відкриваються лише після підписання договору на регулярні відправлення.

---

## 3. Договір (опційно для старту)

Для запуску інтеграції договір не потрібен — публічного API достатньо. Але для:
- знижених тарифів на масові відправлення
- автоматичного формування накладних
- пріоритетної техпідтримки

— варто підписати договір на корпоративне обслуговування. Менеджер Укрпошти оформлює його після надсилання запиту.

---

## 4. Що зробить розробник після отримання токенів

1. Додасть нові поля в БД для збереження карієра та відділення (узагальнить поточну схему, яка зараз НП-only)
2. Підключить Укрпошту як другий варіант доставки в чекауті сайту
3. Додасть вибір Укрпошти в Telegram-боті
4. Підключить трекінг — статуси посилок Укрпошти автоматично оновлюватимуться так само, як для НП
5. Адмін-панель показуватиме карієра в кожному замовленні

**Прогноз часу на впровадження:** ~2–3 робочих дні після отримання токенів.

---

## 5. Прогнозований обсяг

Поточний потік — приблизно 30–50 замовлень на місяць (зростає). Це далеко в межах безкоштовного ліміту API Укрпошти (десятки тисяч запитів на добу).
