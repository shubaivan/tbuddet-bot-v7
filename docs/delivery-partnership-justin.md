## Що відбувається після отримання відповіді

1. Підписуємо договір та надсилаємо документи юридичної особи
2. Отримуємо доступ до API + менеджера техпідтримки
3. Розробник інтегрує Justin як третій варіант доставки (~2–3 дні після отримання креденшіалів)
4. Тестуємо в sandbox → переходимо на production
5. Запускаємо для клієнтів

## Альтернатива, якщо API закритий

Якщо повний API доступний лише після значного обсягу — як проміжне рішення можемо вбудувати **JS-віджет Justin** для вибору поштомата (іframe на checkout). Це швидше, але дає менше контролю.
